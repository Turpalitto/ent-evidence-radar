### Fixed
- **Europe PMC: структурированные аннотации склеивались.** `<h4>Methods</h4>text` после снятия тегов превращалось
  в «Methodstext», абзацы `<p>` — в «loss.Methods:»; из-за этого секции, вывод (Conclusions), PICO и поиск по
  таким аннотациям не работали. Новый `htmlAbstractToText` даёт формат PubMed-парсера («Label: text» построчно);
  уже сохранённые записи чинятся попутно при переклассификации (`repairGluedAbstract`, счётчик `changed.abstract`).
  Парсер секций понимает JAMA- и Lancet-стиль (Importance, Design/Setting/Participants, Main Outcomes and Measures,
  Conclusions and Relevance, Findings, Interpretation, Trial Registration, Funding…), «Interpretation» считается
  выводом; русские подписи для новых секций.
- Английский интерфейс: сгенерированная аннотация записи ClinicalTrials.gov («Статус: …», «Результаты в реестре
  пока не опубликованы») и журнал «ClinicalTrials.gov (реестр)» переводятся при показе — в карточке, превью ленты,
  Atom-ленте `?lang=en` и дайджесте (формат хранения не меняется, `trials.ts` по-прежнему читает русские фразы).
- Пакетная запись статей: невалидная дата из источника (`Invalid Date`) приводила бы к ошибке запроса и
  откату всей транзакции вставок — теперь она сбрасывается в `null` ещё при планировании записи.
- PubMed: дата из `MedlineDate` («2024 Nov-Dec», «2023 Dec 15-31») берёт первый месяц диапазона, а не
  1 января — записи больше не «стареют» на год в сортировке и окне «за N дней».
- medRxiv: расширен словарь ЛОР-терминов для отбора из смежных категорий (pharyn/trache/deaf/audiolog/
  Ménière/cholesteatoma/tympan/parotid/snoring/facial nerve…), теги в заголовке и аннотации снимаются,
  авторы «Last, F. M.» приводятся к «Last FM» (как у PubMed) — единообразные цитаты и экспорт.
- Классификатор дизайна (`CLASSIFIER_VERSION = 6`, существующие записи переразмечаются автоматически):
  исправления к статьям (`Published Erratum`, `Erratum to: …`, `Correction: …`, `Expression of concern`) больше
  не наследуют дизайн оригинала («Erratum to: Randomized trial…» получал РКИ уровня 2); нерандомизированные и
  квазиэкспериментальные дизайны (single-arm, before-and-after, interrupted time series, quasi-experimental,
  uncontrolled) → когорта; перекрёстный дизайн без слова «рандомизированный» → РКИ с низкой уверенностью;
  «observational study», «real-world evidence», «propensity score», «cohorts» (мн. ч.) → когорта;
  «pooled analysis of … trials» и объединённые анализы РКИ по акронимам (SINUS-24/SINUS-52) → вторичный анализ;
  «development and (external) validation», «deep learning for detection», CNN → диагностическая точность;
  Delphi / экспертный консенсус → руководство. Europe PMC больше не отдаёт служебные уведомления (опечатки,
  отзывы, expression of concern) — та же фильтрация по типу публикации, что и у PubMed.
- Индекс доверия: служебное уведомление (erratum/corrigendum/expression of concern как отдельная запись)
  получает −30 — исправление в журнале Tier 1 больше не обгоняет серии случаев. Белый список журналов:
  +OTO Open, +Neurosurgery.
- Размер выборки: распознаются числительные словами («Forty-eight children», «Two hundred and six patients»)
  и пробел как разделитель тысяч («12 345 adults», раньше читалось как 345). Субспециальности: `thyroidectomy`
  → опухоли головы и шеи (паттерн требовал пробел), ангиофиброма/носоглотка → ринология, «… in adults» без
  детских терминов больше не помечается как детская ЛОР из-за слова «tonsillectomy».
- Лента: подписка на `Notification.permission` через Permissions API больше не вешает слушатель `change`,
  если компонент размонтировался до резолва `permissions.query()` (утечка слушателя). Новые тесты
  `feed/hooks.test.tsx` (5): Permissions API, отписка при unmount, поздний резолв, отказ API, online/offline.
- HTTP-клиент источников: после последней неудачной попытки больше не ждёт backoff/`Retry-After` перед тем,
  как отдать ошибку (NCBI присылает `Retry-After` до 60 с — каждый сбой источника держал обновление лишние
  десятки секунд). Тесты `http.test.ts`: 5xx с backoff, 4xx без повтора, таймаут через `AbortController`,
  сетевая ошибка с повтором, штраф очереди после 429.
- **Docker-образ не содержал `public/`**: standalone-сборка Next.js не копирует статику сама, а `Dockerfile`
  копировал только `.next/static`. В контейнере были недоступны `/sw.js` (офлайн-режим и PWA), шрифты Inter
  (`/fonts/*.woff2` → системные шрифты) и `/og.png`. Нашла smoke-проверка в CI (`scripts/smoke.mjs`,
  первый прогон на контейнере). Добавлено `COPY /app/public ./public`; smoke теперь проверяет шрифт и `og.png`
  явно (32 проверки).
- Экран «Темы мониторинга»: ошибки действий (включение, правка запроса, удаление) без входа или при сбое
  сети терялись в консоли — теперь показываются над списком с текстом сервера («Требуется авторизация»
  вместо «HTTP 401»); ошибка формы отделена от ошибки списка.

### Changed
- Цитирование: Vancouver помечает препринты по NLM («medRxiv [Preprint]. 2025.») вместо русского «Препринт.»
  в международном формате; записи ClinicalTrials.gov цитируются как реестр («ClinicalTrials.gov. 2026.
  Identifier: NCT…»), в BibTeX — `@misc` с `howpublished`/`note`. ГОСТ без изменений.

  «Статус: завершено», «фаза 2/3» (`NA` опускается), «Маскирование: двойное». Старые записи с кодами
  (`COMPLETED`, `PHASE3`, `QUADRUPLE`) читаются по-прежнему и обновятся при очередной проверке реестра.
- Бейдж дизайна в ленте и карточке помечается «?» (с подсказкой), если дизайн определён с низкой
  уверенностью — по аннотации или перекрёстному заголовку без слова «рандомизированный»; раньше это было видно
  только в раскрытой секции «Почему такой дизайн».
- Старт БД и общий rate-limit пишут структурированные JSON-события вместо текстовых `console.*`
  (`db.migrations_pending`, `db.pre_migration_backup_failed`, `db.migrate_on_start_skipped`,
  `db.pglite_in_production`, `db.pglite_open_failed`, `db.pglite_quarantined`, `ratelimit.shared_unavailable`) —
  единый формат логов для агрегаторов; в тестах логгер по-прежнему молчит.
- Планировщик вынесен из `src/instrumentation.ts` в чистую фабрику `src/lib/scheduler.ts`
  (`createScheduler(deps)`, `parseAutoBackupHours`, `isRefreshDue`) с инъекцией зависимостей и часов;
  `instrumentation.ts` только связывает зависимости и таймер (интервал теперь `unref`, как и описано в
  ARCHITECTURE). Поведение не изменилось.
- `SettingsPanel.tsx` (524 → 176 строк) разделён: `components/settings/` — `Section` (карточка и классы
  полей), `DigestSection` (дайджест: параметры, статус, предпросмотр, отправка), `BackupSection`
  (выгрузка и восстановление), `DiagnosticsSection` (диагностика и действия администратора), `format.ts`
  (`fmtBytes`/`fmtDuration`). Семь компонентных тестов настроек проходят без правок.

### Fixed
- Кнопка «Обновить данные»: опрос состояния начинался до ответа на `POST /api/refresh`, и первый тик
  мог увидеть «не запущено» раньше, чем сервер зарегистрировал запуск, — кнопка преждевременно
  показывала «Обновление завершено», а пришедший затем `runId` уже не отслеживался. Теперь фазы
  `starting → polling` разделены: опрос стартует только после ответа сервера; при подхвате чужого
  запуска на монтировании собственный клик пользователя имеет приоритет.
- Статистика: скрытые врачом записи (A-11) исключались из итогов, но просачивались в срезы по
  источникам, дням, неделям, годам и в гистограмму индекса доверия — теперь все агрегаты считаются
  только по видимым статьям (тест `stats.test.ts`).
- Workflows `Scheduled refresh` и `Weekly digest` больше не падают, если в окружении `production` не задан
  секрет `APP_URL` (деплой не на Vercel/без внешнего cron): шаг пропускается с уведомлением в логе.
  Секреты передаются через `env:` job'а; при пустом `API_SECRET` выводится предупреждение.

## [0.2.0] — 2026-10-14

Итог аудита (`docs/AUDIT_REPORT.md`, 28 пунктов дорожной карты): безопасность и надёжность продакшена,
классификатор v5 с объяснениями, полнотекстовый поиск, Crossref/КИ-отслеживание, PWA-офлайн, английский
интерфейс, OpenAPI и контракт-тесты, CI с Docker-smoke. Миграции 0008–0017 применяются автоматически
(`npm run db:migrate` / при старте); переклассификация базы под `CLASSIFIER_VERSION = 5` идёт фоном

### Fixed

Интеграционный тест обновления больше не зависит от доступности Crossref (мок).
- Автосброс повреждённого PGlite больше не стирает данные молча — только при `PGLITE_RESET_ON_FAILURE=1` (F-02).
- Разбор PubMed XML со смешанным контентом (`<i>`, `<sup>`) не терял части аннотаций (F-03).
- Валидация входных данных всех API через zod; 400/404 вместо 500, единый формат `{error}` (F-10, I-07).
- CSV-экспорт экранирует формулы; дайджест рассылается через BCC (F-20, F-21).
- Статус PubMed «partial», если упала часть тем; гонка запросов и тройная загрузка ленты на маунте (F-18, F-19).
- Согласована схема drizzle и снапшоты миграций (`npm run db:check`) (F-16).
- Продакшен-сборка падала на `dns`/`net`/`tls`: клиентская карточка импортировала подписи статусов КИ из `@/lib/trials`, который тянет `@/db`. Подписи вынесены в `src/lib/evidence/trial-status.ts`; добавлен тест-страж границы клиент/сервер (обход графа импортов всех `"use client"`-файлов). Устранены предупреждения Turbopack о трассировке всего проекта из-за `readdir(BACKUP_DIR)`.
