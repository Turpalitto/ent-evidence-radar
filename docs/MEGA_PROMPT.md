# МЕГА-ПРОМТ: ENT Evidence Radar

**Роль:** senior fullstack-инженер + специалист по доказательной медицине (EBM).
**Задача:** построить веб-приложение-агрегатор свежих доказательных данных по мировой оториноларингологии.

## 1. Источники (только доверенные, официальные API)
1. **PubMed / MEDLINE** — NCBI E-utilities (esearch → efetch XML), MeSH-фильтры, `[pt]` типы публикаций. Основной канал.
2. **Cochrane Library** — через PubMed (журнал *Cochrane Database of Systematic Reviews*).
3. **Europe PMC** REST API — дублирующий канал, препринты помечаются.
4. **ClinicalTrials.gov API v2** — новые/обновлённые РКИ, наличие результатов.
5. **medRxiv** API — препринты (otolaryngology), явная пометка «не рецензировано», штраф к доверию.
6. **Клинические руководства** — PubMed `guideline[pt]`/`practice guideline[pt]`, приоритет AAO-HNS, NICE, EPOS/EAACI, ESPO, WHO, EUFOREA.

## 2. Доказательная логика
- Классификация дизайна: SR/MA → Guideline → RCT → Cohort → Case-control → Case series/report → Narrative/expert → Preprint.
- Уровень доказательности Oxford CEBM 1–5 автоматически.
- Индекс доверия 0–100: дизайн + tier журнала (белый список) + регистрация протокола (PROSPERO/NCT) + размер выборки + MEDLINE-индексация − штрафы (препринт, хищнический журнал, ретракция).
- Субспециальности: отология/аудиология, вестибулология, ринология/аллергология, ларингология, опухоли головы и шеи, детская ЛОР, сомнология, лицевая пластика, инфекции, кохлеарная имплантация.
- Дедупликация: DOI → PMID → нормализованный заголовок.

## 3. Функции
- Обновление по кнопке и по расписанию (instrumentation.ts, mutex от параллельных запусков, настраиваемый интервал).
- Настраиваемые темы (PubMed-запросы), предустановленный набор.
- Лента с фильтрами (субспециальность, дизайн, уровень, мин. доверие, источник, период, избранное/непрочитанные, поиск), сортировка.
- Карточка статьи: аннотация, авторы, журнал, MeSH, ссылки DOI/PubMed/PMC/CT.gov, объяснение балла доверия, прочитано/избранное, заметки.
- Журнал запусков с ошибками по источникам.
- Статистика: уровни, субспециальности, источники, динамика 30 дней.
- Экспорт CSV / RIS / JSON.
- Rate-limit NCBI (≤3 req/s, поддержка `NCBI_API_KEY`), таймауты, retry, изоляция сбоев источников.
- Русский интерфейс, плотный медицинский дашборд, адаптивность.

## 4. Стек
Next.js App Router, PostgreSQL + Drizzle ORM, Tailwind. Таблицы: sources, topics, articles, fetch_runs, settings.
Дисклеймер: инструмент мониторинга литературы, не заменяет клиническое суждение.
